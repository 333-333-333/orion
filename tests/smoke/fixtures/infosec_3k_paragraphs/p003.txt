An organization protects information by implementing governance, policies, procedures, controls, monitoring mechanisms, and incident response processes. A security policy is a formal document that defines rules and expectations for protecting information. A security standard is a type of control document that defines mandatory requirements. A security procedure is a type of operational document that defines step-by-step activities. A security guideline is a type of advisory document that recommends good practices. A security baseline is a minimum set of controls required for a system, application, or infrastructure component.
