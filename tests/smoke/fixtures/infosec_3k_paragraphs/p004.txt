The board of directors provides strategic oversight for information security. Senior management approves security policies and allocates resources for security initiatives. The information security manager coordinates the information security program. The asset owner classifies information assets and defines protection requirements. The asset custodian operates and maintains the technical environment that stores or processes information. The system administrator manages servers, networks, operating systems, and technical services. The security analyst monitors security events and investigates suspicious activity. The auditor evaluates compliance with security requirements. The end user accesses systems and must follow security policies.
